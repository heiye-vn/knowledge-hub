# Knowledge Hub Web 前端应用（占位）

本目录为前端知识库管理工作台与 AI 对话界面的预留位置。

## 后续初始化指南

当准备开启前端开发时，可直接在 `apps/` 目录下执行如下指令生成 React + Tailwind CSS 工程：

```bash
# 进入 apps 目录
cd apps

# 使用 Vite 初始化 React + TypeScript 项目
pnpm create vite web --template react-ts

# 进入 web 目录安装 Tailwind CSS 依赖
cd web
pnpm add -D tailwindcss @tailwindcss/vite
```

> **注意**：当前保持纯净占位状态，不引入任何多余依赖，不会影响根工作区和后端项目的构建与运行。
