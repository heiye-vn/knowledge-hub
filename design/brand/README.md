# kbase — 字母标（负形底块版）

## 一、定位

| 项 | 内容 |
|---|---|
| 风格 | **字母标（Lettermark）** — 用户点名第 2 项 |
| 方向 | **负形底块** — 用户选定第 3 项 |
| 骨架字母 | `K`（Knowledge / 库），品牌名确定后按同骨架替换 |
| 画布 | 1024 × 1024 正方形，主体占 68% |
| 输出 | PNG 1024 / 512 两档 + 小尺寸矢量版 `kbase-mark.svg` |

## 二、设计说明

**概念一句话**：一块实心的骨白方块是「知识库本体」，从中挖出的字母是被检索出来、递到用户面前的那一条答案。负形本身就是「从知识体里提取」这个动作，不靠额外图形解释。

**构图逻辑**：方块居中、四周留 15.6% 安全边距；K 在方块内占 68% 高，做光学右移 8px 补偿（K 的竖干视觉偏重，机械居中会显得左倾）。所有笔画端点保持水平或垂直切，字面干净。

**字形逻辑**：以粗体无衬线字形为骨架，做两项实质改造 —— ① 宽高比由 0.78 压缩至 0.62，纵向拔高、横向收窄，摆脱原字体的通用感；② 笔画整体加粗，竖干占比提到 24%，保证 48px 时笔画仍有 2.7px。改造后它不再等于任何一款现成字体的 K。

**色彩逻辑**：深墨蓝骨架（L 18% / S 41%）压住画面，骨白承担过渡，青铜金只在方块底部露出一道 18px 的「纸边」——读作纸页叠层的厚度，暗示知识是一摞而不是一张。

## 三、色彩规范

| 角色 | HEX | RGB | HSL | 占比 | 用途 |
|---|---|---|---|---|---|
| 骨架 Skeleton | `#1B2A41` | 27, 42, 65 | 216° 41% 18% | 60% | 画布底 + 字母（负形） |
| 过渡 Transition | `#EFEDE6` | 239, 237, 230 | 47° 22% 92% | 38% | 方块主体 |
| 点睛 Accent | `#B08D4F` | 176, 141, 79 | 38° 38% 50% | **1.2%** | 底部纸边，全场唯一一处 |
| 反白版 | `#1B2A41` 底 + `#FFFFFF` 字 | — | — | — | 浅色页面使用 |

- 色相总数 3，符合上限
- 骨架与过渡明度差 74，灰度稿层次成立
- 无渐变、无投影、无描边包裹
- 点睛色面积 1.2%，低于 5% 上限，且不承担识别功能

## 四、交付文件

| 文件 | 说明 |
|---|---|
| `kbase-A-1024.png` | **主版**：含底部纸边，1024 × 1024 |
| `kbase-A-512.png` | 主版 512 档，用于 Web 与商店 |
| `kbase-B-1024.png` | **备版**：纯双色，去掉纸边，1024 × 1024 |
| `kbase-B-512.png` | 备版 512 档 |
| `kbase-mark.svg` | **小尺寸矢量版**（32px 网格，反白）：去纸边、方块 rx=2.4、负形 K 竖干 24%、双臂等厚 3.21。顶栏 28px、favicon、App 内品牌标一律用它；代码内使用 `apps/web/src/components/BrandLogo.tsx`（同一几何，勿各自修改） |

选型建议：需要「有材质、有讲究」的观感用 A；需要印刷、单色复现、或严格双色规范时用 B，它去掉点睛色后依然是完整标志。

## 五、缩放表现

| 尺寸 | 保留 | 舍弃 |
|---|---|---|
| 1024 | 全部细节，纸边厚度清晰 | — |
| 512 | 纸边仍可见（9px），K 轮廓锐利 | — |
| 96 | 纸边收为一道细线 | 边缘的细微圆角差异 |
| 48 | 字母结构完整，方块边界明确 | 纸边基本消失 |
| 32 | K 仍可辨认（笔画 2.7px） | 纸边完全消失，建议仅用于 favicon 临时场景 |

32px 以下若需要长期使用，建议另做一版「去掉方块、只留加粗 K」的简化图标，不要靠这版硬缩。

## 六、使用规范

- 最小安全边距：四周不小于方块边长的 12%
- 深色页面直接用原版；浅色页面用反白版（深蓝方块 + 骨白 K），不要给方块加描边
- 单色场景用纯黑白版：黑底 + 白方块 + 黑 K
- 禁止：加投影、加渐变、给方块描边、改变纸边颜色与厚度比例、把 K 换成其他字重

## 七、待确认

1. **品牌名**：当前以 `K` 打样。名字确定后按同一骨架替换字母 —— 若首字母不是 K，骨架、比例、负形结构全部沿用，只换字形来源；若是双字母（如 KB），需要重新分配字距与方块比例，属于一次小改版。
2. **字体授权**：当前骨架来自系统粗体字形，改造幅度较大但并非定制字形。若品牌长期使用且预算允许，建议后续请字体设计师基于此骨架做一次完全的定制转曲，彻底脱离原字体。
